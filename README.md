# CineVault – Movie Management System

## Project Description
CineVault is a lightweight Movie Management System developed as a Data Structures academic project. It allows users to manage movie details through a simple web interface.

## Objectives
- Store movie details such as title, genre, release year and rating.
- Implement a Singly Linked List.
- Use file handling for permanent storage.
- Provide a user-friendly web interface.
- Connect the frontend with a C-based HTTP server.

## Technologies Used
- C Programming
- HTML
- CSS
- JavaScript

## Data Structure Used
Singly Linked List

## File Handling
Movie records are stored in movies.dat.

## Main Features
- Add movie details
- Display movie collection
- Store movie records
